# IdeaSpark — デザインアイディアジェネレーター

## プロジェクト概要
デザインの方向性が決まっていない段階で、プロのデザインアドバイザーとの**ヒアリング形式のチャット**を通じて、Web/アプリのデザインコンセプトを引き出すツール。

---

## 機能一覧

### ✅ 実装済み
| 機能 | 説明 |
|------|------|
| **ヒアリング型チャット** | 7段階の質問を順番に出し、回答を積み上げながらアイデアを精度高く生成 |
| **選択ボタン** | 各質問にクイック選択ボタンを併設。クリック1つで回答可能 |
| **フリーテキスト入力** | 選択肢にない答えを自由に記入して送信できる |
| **複数選択（multi）** | 雰囲気・ムード選択で複数タグを選べる |
| **スキップ機能** | 参考サービスや制約は「スキップ」ボタンで任意回答 |
| **ヒアリングサマリー** | 全質問が終わると収集した回答を一覧表示 |
| **アイデア提案（4件）** | ヒアリング結果から最適なデザインコンセプトをIDEA_DBから4件選出 |
| **リスタートボタン** | 提案後にヒアリングをやり直せる |
| **アイデアカード** | カテゴリ・スタイル・説明・タグ・カラーパレットを表示 |
| **詳細モーダル** | カードクリックで機能リスト・カラー・メタ情報を表示 |
| **ブックマーク保存** | アイデアをlocalStorageに保存・解除 |
| **保存済みタブ** | 保存したアイデアを一覧表示・削除 |
| **ムードボードタブ** | 保存済みをカテゴリフィルタ付きビジュアルボードで整理 |
| **コンセプトコピー** | アイデアのテキストをクリップボードにコピー |

### ❌ 未実装

## データモデル

### IDEA_DATABASE（js/data.js）
```json
{
  "id": "mob-001",
  "category": "mobile",
  "style": "minimal",
  "mood": "calm",
  "colorKey": "purple",
  "title": "ウェルネストラッカー",
  "description": "...",
  "features": ["...", "..."],
  "tags": ["health", "mobile"],
  "palette": ["#ffffff", "#7c6ff7", "#e8e8f0", "#1e1e2e"]
}
```

### ヒアリングフロー（7ステップ）
1. `platform` — スマホ / Web / 両方
2. `purpose` — 目的・ジャンル（選択 or 自由入力）
3. `user` — ターゲットユーザー（選択 or 自由入力）
4. `mood` — 雰囲気・感情（複数選択）
5. `style` — ビジュアルスタイル（選択）
6. `reference` — 参考サービス（自由入力 or スキップ）
7. `constraint` — 制約・こだわり（選択 or 自由入力 or スキップ）
